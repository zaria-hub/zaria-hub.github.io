AI-Generated Media Detection System — Multi-Modal Deepfake and Synthetic Content Detector

Designed and built an end-to-end deepfake detection system combining computer vision, transfer learning, and full-stack deployment — covering both image and video modalities with independently trained, purpose-built models, backed by an iterative, evidence-driven development process rather than a single one-shot training run.

Key Features:

  • Diagnosis & Root-Cause Analysis: After deploying a first version (frozen CLIP embeddings + linear classifier, trained solely on DFDC) that scored well on held-out validation data (Macro F1 ≈ 0.80) but failed catastrophically on personal test photos — misclassifying everything as "fake" — traced the failure to a genuine distribution shift rather than a class-imbalance artifact. The model had learned dataset-specific fingerprints (DFDC's video compression profile, face-cropping pipeline) instead of generalizable manipulation cues.
  • Dataset Expansion for Domain Robustness: Sourced Celeb-DF-v2 (a face-swap dataset built from an entirely different actor pool and pipeline) as raw video, then re-extracted faces in-house using MTCNN with fixed, reproducible parameters (image_size=224, margin=40) — the same exact parameters later enforced at inference time, closing the preprocessing mismatch that caused the original failure. Merged the new data with DFDC only after verifying zero video-level leakage between train and validation splits. Worked through real-world engineering friction along the way: disk space exhaustion, dependency conflicts across numpy/pandas/torchvision/transformers, and a mid-project data-loss scare that was resolved once the underlying storage location was correctly identified.
  • Architecture Upgrade — from Frozen Features to Fine-tuning: Replaced the frozen-CLIP approach with genuine fine-tuning of a pretrained ViT-based deepfake classifier (dima806/deepfake_vs_real_image_detection), freezing the majority of the backbone and unfreezing only the final transformer blocks plus classification head. Trained on the merged, leak-checked dataset with a class-weighted loss to address label imbalance. Final result: Macro F1 = 0.8136, with improved video-level accuracy after majority-vote aggregation across frames. Exported the model in its full, portable format (config.json, model.safetensors, preprocessor_config.json) rather than raw weights alone, ensuring reliable reload for deployment.
  • Backend Integration: Extended a FastAPI service with two fully independent inference paths — /predict_image (unchanged CLIP + linear-classifier pipeline) and /predict_video (the new fine-tuned ViT model), with MTCNN preprocessing in the video path locked to the exact parameters used during training — the single most important fix carried over from the root-cause diagnosis.

Tech Stack: Python, PyTorch, Hugging Face Transformers, CLIP (ViT-B/32), fine-tuned Vision Transformer, MTCNN (facenet-pytorch), FastAPI, OpenCV, scikit-learn (metrics), Kaggle/HuggingFace data pipelines
