Brain Tumor Segmentation – Medical Image AI System

Designed and built an end-to-end deep learning pipeline for automatic brain tumor detection and segmentation in MRI scans, combining a trained convolutional neural network with a full-stack web interface to enable real-time visual diagnosis support from image upload to result visualization.

Key Features:

Segmentation Model: U-Net architecture with a pretrained ResNet34 encoder (transfer learning from ImageNet) trained on labeled MRI slices to pixel-wise classify tumor vs. healthy tissue

Custom Training Pipeline: combined BCE + Dice loss to handle severe class imbalance (tumors occupy a small fraction of each scan), with train/validation split, data augmentation (flips, rotation, brightness), and automatic best-checkpoint saving based on validation Dice score

Model Evaluation: tracked Dice coefficient and IoU across training, achieving 0.84 validation Dice score on held-out data

Inference API: Flask backend serving the trained model, accepting uploaded MRI images and returning predicted tumor masks, contour overlays, affected area (px/%), and mean model confidence as JSON

Custom web interface: hand-built HTML/CSS/JS frontend (radiology-viewer inspired dark UI) with drag-and-drop image upload, live scan-animation feedback during inference, toggleable original/overlay view, and one-click download of predicted masks

Cloud-to-local ML workflow: trained on GPU via Google Colab, exported the checkpoint, and deployed inference locally with a lightweight CPU-only runtime for practical, low-cost usage

Full-stack ownership: from raw labeled dataset and PyTorch model architecture, through the loss/metrics design, to the API layer and browser-facing product — demonstrating applied ML engineering beyond notebook-only prototyping

Tech Stack: Python, PyTorch, segmentation-models-pytorch (U-Net + ResNet34), OpenCV, NumPy, Flask, HTML/CSS/JavaScript, Google Colab (CUDA training), REST API design, Dice/BCE loss, Dice & IoU evaluation metrics
