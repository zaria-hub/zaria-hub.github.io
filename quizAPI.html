AI-Powered Quiz Generator

Built an intelligent quiz generation engine that automatically creates high-quality educational quizzes from any given text, powered by Groq's LLM API (Llama 3.3 70B). The system uses carefully engineered prompts to ensure generated questions are strictly grounded in the source content , with configurable difficulty levels and question formats to suit different learning needs.

Key Features:

  • Generates customizable quizzes with adjustable number of questions and difficulty (Easy, Medium, Hard)
  • Supports multiple question formats like Multiple Choice, True/False, Fill in the Blank, or a Mixed set
  • Strict content-grounding rules ensure every question and correct answer is directly supported by the source text — preventing hallucinated content
  • Structured prompt engineering to guarantee consistent, parseable output format
  • Plausible, non-trivial distractors for MCQs to improve quiz quality and learning value

Tech Stack: Python, Groq API (LLM inference), Prompt Engineering, REST API integration
