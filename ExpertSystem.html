Disease Diagnosis Expert System

Developed a rule-based expert system in C++ (.NET / Windows Forms) that helps users explore possible health conditions based on selected symptoms. The application features a bilingual (English/Arabic) graphical interface with symptoms organized into intuitive categorized tabs (General, Respiratory, Digestive, Eyes, Skin, Heart), allowing users to interactively select symptoms and receive potential diagnosis suggestions through a rule-based inference engine.

Key Features:

  • Interactive symptom-selection interface with visual feedback (toggle-based buttons)
  • Symptoms organized into medical categories using a tabbed layout for improved usability
  • Rule-based inference engine mapping symptom combinations to primary conditions (e.g., cold, diabetes, anemia, asthma, allergies, heart disease, high blood pressure, poisoning)
  • Secondary-level reasoning that cross-references detected conditions to suggest more specific diagnoses (e.g., COVID-19, lung cancer, lupus, viral intestinal diarrhea)
  • Full bilingual support with real-time UI language switching between English and Arabic
  • Reset functionality to clear all selections and restart the diagnostic process
  • Custom-styled, responsive Windows Forms UI with dynamically generated buttons and adaptive layout

Tech Stack: C++/CLI, .NET Framework, Windows Forms, Rule-Based Expert System Design
