No-Code Data Mining & Machine Learning Platform

Designed and developed a no-code web application that enables users to perform end-to-end data mining and machine learning workflows without writing a single line of code. Built with Streamlit, scikit-learn, Pandas, and Seaborn, the platform guides users through a structured pipeline: uploading datasets (CSV/Excel), exploring data through interactive visualizations and statistics, preprocessing (missing value handling, encoding, and scaling), training machine learning models, and reviewing performance results — all through an intuitive interface.

Key Features:

  • Upload and preview CSV/Excel datasets instantly
  • Automated exploratory data analysis (EDA) with histograms and correlation heatmaps
  • Flexible preprocessing options: missing value imputation, categorical encoding, and feature scaling
  • Support for multiple machine learning tasks: Classification, Regression, and Clustering
  • Multiple algorithms available, including Logistic Regression, Random Forest, Linear Regression, K-Means, and DBSCAN
  • Real-time model evaluation with accuracy scores, confusion matrices, RMSE, R², and silhouette scores

Tech Stack: Python, Streamlit, Pandas, NumPy, scikit-learn, Matplotlib, Seaborn
